# 逃离塔科夫 · 赛季服任务引导

单文件网页：501 条任务的中英双语任务库 + 跑图规划 + 地图查看器。
任务数据抓取自 eftarkov.com，英文名取自游戏本体语言文件。

## 地图图片

仓库不含地图图片。想自动加载，在 index.html 旁边建 `maps` 文件夹，按中文名放图
（webp / jpg / jpeg / png 都认）：

    maps/海关.webp
    maps/森林.webp
    maps/海岸线.jpg

地图可到 https://www.eftarkov.com 的地图区自行保存；也可以直接在页面里点
「载入地图」手动上传，图片只存在自己的浏览器里。

## 说明

- 完成进度、规划清单、地图标记都存在浏览器本地，不会上传
- 换设备用页面里的「备份」导出 / 导入
